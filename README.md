# Inverse discrete fourier transformation 
[Building on a previous project ](https://github.com/LukeMAmos/UsingFFT)
 looking to understand how the FFT works and its implementation in audio , this project looks to complete the inverse operation , the end goal is to build a piece of software that records 5 seconds of audio , and then resynthesizes the audio using only the highest magnitude bins. 

## Files 
- Research notes , including the implementation of the Inverse Fast Fourier Transform and how it relates to the Fast Fourier Transform 
- Source code for the project
- .jucer file for building the code

## Built using 
- JUCE Framework 
- C++
